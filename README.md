# 覓長生傳承（MiChangSheng_LiHuo）

《了不起的修仙模擬器》Mod：把《覓長生》寧州門派的功法與神通機制搬進修仙模擬器，範圍到**金丹期**。

> 機制參考自《覓長生》，名稱沿用原作，**僅供個人遊玩**。
> 視覺效果需要同時啟用 [九霄流光訣](https://github.com/alex84425/amazing_shusame)（`main` 分支）的特效引擎。

## 目前收錄

| 門派 | 屬性 | 功法 | 神通 | 被動功法 | 招牌機制 |
|---|---|---|---|---|---|
| **離火門** | 火 | 烈焰訣 | 19 | 11 | 灼燒、焰、化焰、連擊（上一招木系） |
| **竹山宗** | 木 | 春草訣 | 16 | 11 | 中毒、纏繞、吸血、引毒、連擊（上一招水系） |

## 核心設計：把回合制搬進即時戰鬥

- **戰鬥中每 3 秒算一回合**
- **五行靈氣**：每回合依弟子的五行根基權重抽取金木水火土靈氣（煉氣 3／築基 4／金丹 5 點），超過上限（8／12／16）會在回合結束消散
- **出招**：
  - 交給 AI：每一步替付得起的技能評分，挑最高分的施放，考慮連擊、【同】、後繼無力、狀態層數上限
  - 照玩家順序：在「出招設定」視窗排好優先順序，每回合由上往下找第一個付得起且啟用的招式
- **傷害換算**：覓長生點數 × 境界倍率（煉氣 12／築基 15／金丹 20），經 `ReduceLingDamage` 打在靈氣上（帶五行屬性）
- **狀態**：灼燒（每層 0.2×倍率，回合開始結算後減一層）、中毒（每層 0.15×倍率，回合結束結算，不衰減）、纏繞（回合結束清除）、焰、化焰；上限 99 層；**離開戰鬥 6 秒後全部清除**

## 使用方式

1. 啟用本 Mod（建議同時啟用九霄流光訣以顯示特效），重開遊戲
2. 取得功法：開局經歷「離火門弟子」「竹山宗弟子」，或測試用一鍵習得：
   - 離火：選中弟子按 `左Shift + 5`
   - 竹山：選中弟子按 `左Shift + 3`
   - 只有**道修內門弟子**能真正習得（外門弟子與神修學不了秘術）
3. 出招設定：選中修習者按 `左Shift + 4`
4. 建造選單「工作」→「離火試煉木樁」：打不壞的測試靶，每 15 秒在訊息欄回報傷害統計

## 檔案結構

```
Info.json
Scripts/
  MCS_Data.lua           離火門資料（神通、功法、技能樹）
  MCS_Data_ZhuShan.lua   竹山宗資料
  MCS_Core.lua           回合引擎（靈氣、狀態、AI 出招、結算）
  MCS_Host.lua           遊戲本體介面（傷害、狀態顯示、快捷鍵、木樁傷害統計）
  MCS_FX.lua             兩派視覺效果（借用九霄的特效引擎）
  MCS_UI.lua             出招設定視窗、存檔
Settings/                由 Tools/gen_xml.py 從資料檔產生，請勿手改
Tools/
  gen_xml.py             產生所有 XML（功法、技能樹、秘術、狀態、經歷、木樁）
  make_dummy.py          木樁貼圖
  test/index.html        離線測試：瀏覽器內用 fengari 跑真正的引擎，模擬單人與對決
```

修改資料檔後執行 `python Tools/gen_xml.py` 重新產生 XML。離線測試要在 Mod 根目錄開本機伺服器：`python -m http.server 8766`，再開 `http://localhost:8766/Tools/test/`。

## 測試結果（2026-10-18）

**離線對決**（只有門派技能，同境界、各自偏重本系五行）

| 境界 | 結果 |
|---|---|
| 煉氣 | 竹山 3 勝 0 敗 |
| 築基 | 竹山 3 勝 0 敗 |
| 金丹 | 竹山 2 勝、離火 1 勝 |

**遊戲內木樁**（陸鵬雲，離火）：煉氣每秒傷害從 18 升到 59（灼燒越疊越痛）；金丹約 430。

**遊戲內點數賽**（賀冬雲·離火 vs 古波·竹山，煉氣，卸裝、關閉原版秘術、每秒補滿靈氣）：離火 **2098** 比竹山 **1217**。
與離線結果不同的原因：遊戲裡兩人五行效率相同（古波不偏木），而且戰鬥常中斷，中毒的累積優勢被打斷。
